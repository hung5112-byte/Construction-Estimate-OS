## Building types we price by AACE class
- Class 5 (order of magnitude): $/SF models by building type from `benchmarks.md` — ±30–50%
- Class 4 (schematic): assemblies (UniFormat) — ±20–30%
- Class 3 (design development): semi-detailed unit costs — ±10–20%
- Class 2 (bid / construction documents): detailed takeoff, every quantity traced to a sheet — −5/−10% to +5/+15%
