# PROMPT 04: Elevator Pitch

#### Description
A set of elevator pitches for multiple contexts: 30 seconds (networking), 60 seconds (investor), 90 seconds (partner). Each version is customized for a different audience. The CEO and sales team should know them by heart.

#### Information to collect (ask the user before generating)
1. The clearest one-sentence description of the company? ("We help [who] [do what] with [how]")
2. The biggest differentiator vs. competitors? (1-2 sentences)
3. The strongest proof point? (a metric / customer / award)
4. The desired CTA? (meet again / demo / send proposal / follow on social)
5. Which versions do you need? (Investor / Customer / Partner / Recruiting / Media / All)
6. Language: English (or another language for a specific audience)?

#### Suggested template
Structure:
- **30-Second Pitch** (Networking/Elevator) — Hook → Problem → Solution → CTA
- **60-Second Pitch** (Investor/Partner) — Hook → Problem → Solution → Traction → Ask
- **90-Second Pitch** (Deep Intro) — Hook → Problem → Solution → Why us → Traction → Vision → CTA
- **Customize per audience**: Investor (focus: market size, traction, ROI) / Customer (focus: pain point, benefit, proof) / Recruiting (focus: mission, culture, growth) / Media (focus: story, impact, uniqueness)
- **Tips & Practice Guide** — how to rehearse, body language, common mistakes

Confirm the structure before generating.

#### File-generation prompt
```
Create a set of elevator pitches for the business.

CONTEXT:
- Company: [Name] — Industry: [industry]
- 1-liner: "[We help [who] [do what] with [how]]"
- USP: [differentiator]
- Proof points: [metrics/customers/awards]
- Audiences: [Investor / Customer / Partner / Recruit / Media]
- Language: [English / another language for a specific audience]

FORMAT:
- 3 versions: 30s (~75 words) / 60s (~150 words) / 90s (~225 words)
- Customize per audience: 5 audiences × 3 lengths = 15 variations (or choose a combo)
- Each pitch: full script + notes (which words to stress, where to pause, when to make eye contact)
- Scorecard: ☐ Clear? ☐ Memorable? ☐ Differentiating? ☐ Has CTA? ☐ Under time?
- Practice guide: rehearse in the mirror, record & review, A/B test

TONE: Confident, conversational, not recited. A storytelling voice.
LENGTH: 3-5 pages.
```
