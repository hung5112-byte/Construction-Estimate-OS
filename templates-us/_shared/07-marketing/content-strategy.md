### PROMPT 02: Content Strategy

#### Description
An overall content strategy — defining content pillars, content types, distribution channels, an editorial-calendar framework, and content-performance metrics. Ensures every piece of content serves a business goal and matches the brand voice.

#### Information to collect (ask the user before generating)
1. Content-marketing goal? (Brand awareness / Lead gen / Thought leadership / SEO?)
2. Where does the target audience read/watch content? (Facebook, YouTube, TikTok, Blog, LinkedIn?)
3. Current content: what's working? What isn't?
4. Content resources: how many people? In-house or outsourced?
5. Brand voice / tone: professional, friendly, humorous, thought-leader?
6. Current posting frequency? Target frequency?

#### Suggested template
Structure:
- **Content Mission Statement**: "We create content for [audience] to [purpose]"
- **Content Pillars**: 3-5 pillars, each with sub-topics
- **Content Types & Formats**: blog, video, infographic, podcast, case study, social post...
- **Distribution Channels**: owned (blog, email), earned (PR, guest post), paid (ads, sponsored)
- **Editorial Calendar Framework**: cadence, workflow, approval process
- **Content Performance Metrics**: engagement, reach, traffic, leads, conversion
- **Content Governance**: brand voice guide, style guide, approval workflow

Confirm the structure before generating.

#### File-generation prompt
```
Create a Content Strategy.

CONTEXT:
- Company: [Name] — Industry: [industry]
- Content goal: [awareness / lead gen / thought leadership / SEO]
- Audience: [main persona]
- Channels: [Facebook / YouTube / TikTok / Blog / LinkedIn]
- Content team: [number] — [in-house / outsource]
- Brand voice: [tone]

FORMAT:
- Content mission: 1-sentence statement
- Content pillars: table Pillar | Sub-topics | Goal | % of total content | Example
- Content matrix: table Type | Format | Channel | Frequency | Effort | Impact
- Distribution map: Channel | Content type | Frequency | Best time | CTA
- Editorial workflow: flowchart — Ideation → Brief → Create → Review → Approve → Publish → Measure
- Performance framework: table Metric | Definition | Target | Tool | Frequency
- Content audit template: table Existing content | Type | Performance | Keep/Update/Archive

TONE: Creative yet strategic, data-informed.
LENGTH: 6-8 pages.
```
