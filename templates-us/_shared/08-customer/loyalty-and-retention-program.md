### PROMPT 09: Loyalty & Retention Program

#### Description
Design a comprehensive loyalty program — point system, tier benefits, retention tactics, churn prevention, win-back campaigns. The goal: increase LTV (lifetime value), reduce churn, and turn customers into advocates.

#### Information to collect (ask the user before generating)
1. Any current loyalty program? Type? (point / tier / paid / hybrid)
2. Current churn rate? Target?
3. Average LTV? Target increase?
4. Loyalty-program budget? (% of revenue)
5. A CRM/loyalty platform?
6. What loyalty programs do competitors have?

#### Suggested template
Structure:
- **Program Design**: program type, goals, KPIs
- **Point System**: earning rules (purchase, referral, review) + redemption options (discount, gift, upgrade)
- **Tier Benefits**: Bronze → Silver → Gold → Platinum — increasing benefits
- **Retention Tactics**: birthday reward, anniversary, exclusive access, early launch
- **Churn Prevention**: early-warning signals, intervention playbook, save offers
- **Win-back Campaigns**: segment inactive customers, win-back sequence, special offers, deadline

Confirm the structure before generating.

#### File-generation prompt
```
Create a Loyalty & Retention Program.

CONTEXT:
- Company: [Name] — Current loyalty: [yes/no] — Type: [point/tier/paid]
- Churn rate: [%] — Target: [%]
- Current LTV: [USD] — Target: [USD]
- Budget: [% of revenue or USD/year]
- Platform: [CRM/loyalty tool / none]
- Competitors: [describe programs]

FORMAT:
- Program overview: 1-pager — Program name | Goal | Type | Target audience | Launch date
- Point system: table Action | Points earned | Example | Cap/limit
- Redemption menu: table Reward | Points needed | Value | Availability
- Tier benefits: table Tier | Threshold | Benefits (8-10 items) | Upgrade path
- Churn prevention: decision tree — Warning signal → Score check → Intervention → Result
- Win-back sequence: 5-step campaign — Email 1 (miss you) → 2 (feedback) → 3 (offer) → 4 (urgency) → 5 (final)
- ROI projection: Investment | Expected retention improvement | Revenue impact | Payback period (USD)
- KPIs: Enrollment rate | Active rate | Redemption rate | Churn rate | NPS | LTV growth

TONE: Strategic, creative, customer-centric.
LENGTH: 8-10 pages.
```
