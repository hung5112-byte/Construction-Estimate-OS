# P-PPL-11: Recruitment Process SOP

#### Description
A standardized end-to-end recruiting process — from a department's headcount request to the candidate starting. Ensures you hire the right person, at the right time, on budget. General information only — keep hiring practices compliant with EEO law; confirm with an attorney where unsure.

> US note: hiring must comply with federal anti-discrimination law — **Title VII** (race, color, religion, sex, national origin), **ADA** (disability), **ADEA** (age 40+), and Texas Labor Code ch. 21. Verify employment eligibility for every hire via **Form I-9** (8 U.S.C. §1324a). Background-check use is regulated by the **FCRA** (15 U.S.C. §1681) and Texas "ban-the-box"/criminal-history considerations may apply [verify].

#### Information to collect (ask the user before generating)
1. How many interview rounds? (1 / 2 / 3)
2. Who interviews in each round? (HR / Hiring Manager / Owner)
3. Main recruiting channels? (Indeed, LinkedIn, ZipRecruiter, referral, recruiter/agency)
4. Target time-to-hire? (from posting to start)
5. A formal review after the introductory period?
6. An employee-referral program?

#### Suggested template
Structure:
- **Step 1** — Headcount request: hiring manager submits a form → owner/finance approve budget
- **Step 2** — Post & source: channels, content, ad budget; use inclusive, EEO-compliant job language
- **Step 3** — Resume screening: criteria, tools, shortlist
- **Step 4** — Interviews: round 1 (HR screen) → round 2 (technical/hiring manager) → round 3 (owner if needed); use consistent, job-related questions
- **Step 5** — Evaluate & decide: combined scorecard, reference check (FCRA-compliant if using a third-party background check)
- **Step 6** — Offer: negotiate, send offer letter, await acceptance
- **Step 7** — Pre-boarding → onboarding (Form I-9)

Confirm the structure before generating.

#### File-generation prompt
```
Create a Recruitment Process SOP.

CONTEXT:
- Company: [Name] — # interview rounds: [number] — Channels: [list]
- Participants: Round 1 [___] | Round 2 [___] | Round 3 [___]
- Time-to-hire target: [days]
- Referral program: [Yes/No]
- Authority: Title VII / ADA / ADEA + Texas Labor Code ch. 21 (EEO); Form I-9 (8 U.S.C. §1324a); FCRA (15 U.S.C. §1681, background checks)

FORMAT:
- Overall flowchart: Mermaid — 7 steps + decision points + timeline
- RACI per step: Step | HR | Hiring Mgr | Finance | Owner
- Timeline: Gantt — Day 1 (post) → Day X (start)
- Attached templates: Headcount Request Form, Interview Schedule, Reference Check Form
- Recruiting KPIs: Time to fill | Cost per hire | Quality of hire | Offer acceptance rate
- Checklist per step: 3-5 items each
- Compliance note: EEO-consistent questions, I-9 at onboarding, FCRA notice/consent for background checks

TONE: Standard SOP, process-driven, efficient.
LENGTH: 6-8 pages.
```
