# P-PPL-17: 30-60-90 Day Onboarding Checklist

#### Description
A checklist of goals and tasks for a new hire at three milestones: Day 30 (Learn & Understand), Day 60 (Start Contributing), Day 90 (Independent & Formal Review). Helps the employee and manager align expectations and measure progress.

#### Information to collect (ask the user before generating)
1. Length of the introductory period? (the 30-60-90 should fit within or span it)
2. Sample role to customize: Sales / Marketing / Accounting / IT?
3. Who evaluates at each milestone? (Manager / HR / both)
4. Linked to individual KPIs/OKRs?
5. Consequence if the Day-90 milestone isn't met? (extend introductory period / part ways — at-will)

> US note: US employment is at-will, so there's no legally defined "probation." Many companies use an informal "introductory period," but it does not change the at-will relationship. Document performance consistently.

#### Suggested template
Structure:
- **Day 30 — Learn & Understand**: understand the product, processes, team, tools. Output: can describe the core process.
- **Day 60 — Start Contributing**: handle tasks independently, contribute ideas, handle the first cases. Output: measurable output.
- **Day 90 — Independent & Review**: fully independent, hitting baseline KPIs, formal review.

Confirm the structure before generating.

#### File-generation prompt
```
Create a 30-60-90 Day Onboarding Checklist.

CONTEXT:
- Company: [Name] — Introductory period: [1 / 2 / 3 months]
- Sample role: [Sales / Marketing / Accounting / IT]
- Evaluated by: [Manager / HR / Both]
- Linked to KPIs: [Yes/No]

FORMAT:
- 3 separate tables (Day 30, 60, 90): Goal | Tasks | Support needed | Measurement | Status ☐
- Day 30: 8-10 tasks — learn, observe, understand
- Day 60: 8-10 tasks — practice, contribute, feedback
- Day 90: 8-10 tasks — independent, hit KPIs, formal review
- Check-in schedule: Week 1 (daily) → Weeks 2-4 (weekly) → Months 2-3 (bi-weekly)
- Review form per milestone: 5 manager questions + 5 employee self-assessment questions
- Decision at Day 90: Pass ✅ | Extend ⏳ | Part ways ❌ (at-will) — clear criteria

TONE: Supportive, goal-oriented — the new hire sees a clear path.
LENGTH: 3-4 pages.
```
