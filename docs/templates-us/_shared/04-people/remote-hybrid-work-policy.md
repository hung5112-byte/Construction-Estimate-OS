# P-PPL-09: Remote / Hybrid Work Policy

#### Description
A policy setting the conditions, rules, and expectations for working remotely (WFH) or hybrid. Covers equipment, security, hours, communication, and performance evaluation when remote.

#### Information to collect (ask the user before generating)
1. Model: full remote / hybrid (how many WFH days/week) / case-by-case?
2. Which roles can be remote? (field sales OK, but accounting in-office?)
3. Do you provide equipment / internet stipend for WFH employees?
4. Security requirements: VPN? No public Wi-Fi? Lock screen?
5. Monitoring/evaluation: output-based or time-tracking?
6. Home-workspace policy? (quiet, desk, lighting)

> US note: if a remote employee works from a different state, there may be multi-state payroll-tax, workers'-comp, and employment-law implications. Confirm with a CPA/attorney before approving out-of-state remote work. [verify]

#### Suggested template
Structure:
- **Part 1** — Scope: who can be remote, conditions, approval
- **Part 2** — Work model: full remote / hybrid / flexible — rules for each
- **Part 3** — Equipment & expenses: what the company provides, what the employee provides, internet stipend
- **Part 4** — Hours & availability: core hours, meeting hours, response time
- **Part 5** — Security when WFH: VPN, device lock, clean desk, guest restrictions
- **Part 6** — Communication & collaboration: tools, daily check-in, weekly sync
- **Part 7** — Performance evaluation: output-based, KPIs, 1-on-1 frequency
- **Part 8** — Revoking remote privileges: when, and the process

Confirm the structure before generating.

#### File-generation prompt
```
Create a Remote / Hybrid Work Policy.

CONTEXT:
- Company: [Name] — Model: [Full remote / Hybrid / Case-by-case]
- WFH days/week: [number] — Eligible roles: [list]
- Equipment support: [Yes/No] — Expenses: [describe]
- Security: VPN [Yes/No] — Monitoring: [output / time-tracking]
- Tools: [Slack/Teams/Zoom/Asana...]

FORMAT:
- Eligibility matrix: Department/Role | Full Remote | Hybrid | Office only | Conditions
- Equipment checklist: Item | Company-provided | Employee-provided | Expense support
- Core hours: timeline visual — Flexible zone | Core hours (must be online) | Flexible zone
- Security checklist: 8-10 mandatory WFH security items ☐
- Communication protocol: Issue type | Channel | Expected response time
- Performance review: remote-specific KPIs + increased 1-on-1 frequency
- Revocation triggers: 3-5 conditions → revoke remote privilege + process
- Note: out-of-state remote work may create multi-state tax/workers'-comp obligations [verify with CPA]

TONE: Balancing trust and control, modern, flexible yet clear.
LENGTH: 5-7 pages.
```
