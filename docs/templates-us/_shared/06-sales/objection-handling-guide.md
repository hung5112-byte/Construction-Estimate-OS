### PROMPT 07: Objection Handling Guide

#### Description
A consolidated guide to the top 20 most common objections + how to handle each effectively. Applies the LAER framework (Listen, Acknowledge, Explore, Respond) and reframe techniques to turn objections into opportunities.

#### Information to collect (ask the user before generating)
1. Top 10 most common objections today?
2. Hardest objection to handle? Recovery rate?
3. Which product/service is rejected most?
4. Which competitors come up most?
5. Flexibility policies? (discount, trial, warranty, refund?)
6. How does the team currently handle objections? Any training?

#### Suggested template
Structure:
- **LAER Framework**: explains the 4 steps — Listen, Acknowledge, Explore, Respond
- **Top 20 Objections**: one card each:
  - Objection statement
  - Type: Price / Trust / Timing / Need / Competition / Authority
  - The psychology behind it
  - Sample LAER response
  - Reframe technique
  - Follow-up question
- **Objection classification**: table by type + frequency
- **Reframe techniques**: 7 perspective-shifting techniques
- **Do's & Don'ts**: principles for handling objections
- **Practice**: roleplay scenarios
- **Appendix**: objection tracking sheet, win/loss analysis template

Confirm the structure before generating.

#### File-generation prompt
```
Create an Objection Handling Guide.

CONTEXT:
- Company: [Name] — Products/services: [list]
- Top 10 objections: [list]
- Hardest objection: [describe] — Recovery rate: [%]
- Competitors compared: [list]
- Flexibility policies: [discount / trial / warranty / refund]

FORMAT:
- LAER framework: 4-step infographic + illustrative examples
- Objection cards: 20 cards — Objection | Type | Psychology | Sample response | Reframe | Follow-up
- Classification matrix: table Type | Count | Frequency % | Difficulty | Recovery rate
- Reframe techniques: 7 techniques + a concrete example for each
- Comparison handler: table Competitor | Where they're strong | Where we're stronger | Response
- Do's & Don'ts: 2 columns — 10 SHOULD + 10 SHOULD NOT
- Roleplay: 3 scenarios (Price / Competition / Timing) + sample script

TONE: Coaching — natural, empathetic, persuasive but not manipulative.
LENGTH: 8-12 pages.
```
