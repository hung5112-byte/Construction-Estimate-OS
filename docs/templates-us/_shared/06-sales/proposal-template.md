### PROMPT 09: Proposal Template (Professional Proposal / Quote)

#### Description
A professional proposal/quote template — not just a price list, but a presentation of value, solution, timeline, and terms. Helps the rep create an impressive, professional proposal and increase close rates.

#### Information to collect (ask the user before generating)
1. What kind of sale is the proposal for? (project / product / service / retainer)
2. Required sections? (cover, summary, pricing, timeline, T&C)
3. Branding: logo, colors, fonts?
4. Any case studies / testimonials to include?
5. Default payment terms?
6. Format: Word / PDF / online / proposal software?
7. Average proposal length?

#### Suggested template
Structure:
- **Cover Page**: logo, customer name, project name, date, "Prepared by"
- **Executive Summary**: 1 page — Problem, Solution, Value, Investment
- **About Us**: a short company intro, credentials, differentiators
- **Understanding Your Needs**: summary of the customer's needs (customizable)
- **Proposed Solution**: detailed solution, scope, deliverables
- **Pricing & Investment**: a clear price table, options/packages
- **Timeline & Milestones**: Gantt chart, key milestones
- **Case Studies**: 2-3 similar case studies
- **Terms & Conditions**: payment, warranty, liability, IP
- **Next Steps**: a clear CTA — sign, pay, kick-off
- **Appendix**: technical specs, team profiles (if needed)

Confirm the structure before generating.

#### File-generation prompt
```
Create a Professional Proposal Template.

CONTEXT:
- Company: [Name] — Industry: [industry]
- Type: [project / product / service / retainer]
- Branding: [logo / colors / fonts]
- Case studies: [Yes/No] — Count: [number]
- Payment: [deposit % / milestones / full upfront]
- Format: [Word / PDF / Online]
- Average length: [pages]

FORMAT:
- Cover page: 1-page layout — logo, project name, customer, date
- Executive Summary: 4 mini-sections — Problem | Solution | Value | Investment
- Solution section: table Deliverable | Description | Timeline | Responsibility
- Pricing table: Item | Unit | Qty | Unit price | Amount — with subtotal, sales tax, total (USD)
- Options/Packages: comparison table Basic | Standard | Premium (if any)
- Timeline: Gantt chart or table Phase | Duration | Start | End | Milestone
- T&C: 10-12 standard terms, legal but readable (have an attorney review for material deals)
- CTA: clear next steps + contact info + deadline

TONE: Professional, consultative, win-win.
LENGTH: 8-15 pages (template with placeholders).
```
