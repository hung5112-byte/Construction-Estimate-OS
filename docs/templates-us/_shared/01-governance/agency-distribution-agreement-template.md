# PROMPT 15: Agency/Distribution Agreement Template

#### Description
An agency/distribution agreement template — governs commission, territory, exclusivity, quota, and termination. Used for a network of agents/distributors. Governed by Texas contract law. General information only — not legal advice.

#### Information to collect (ask the user before generating)
1. Distribution model? (sales agent / buy-and-resell distributor / affiliate)
2. Exclusive or non-exclusive?
3. Territory: by state/region/nationwide?
4. Commission structure: % / fixed / tiered?
5. A mandatory quota?
6. What product/service is being distributed?

#### Suggested template
Structure:
- **Section 1** — Parties, appointment of the agent
- **Section 2** — Product/service, territory, exclusivity
- **Section 3** — Rights & obligations: principal + agent
- **Section 4** — Price, discount, commission
- **Section 5** — Quota & performance: minimum targets, review periods
- **Section 6** — Marketing & brand: co-branding rules
- **Section 7** — Ordering, delivery, inventory, returns
- **Section 8** — Payment: terms, method, early-payment discount
- **Section 9** — Confidentiality & non-compete
- **Section 10** — Term, renewal, termination
- **Appendix**: rate sheet, commission table, territory map, KPI form

Confirm the structure before generating.

#### File-generation prompt
```
Create an agency/distribution agreement template.

CONTEXT:
- Company: [Name] — Product: [description]
- Model: [agent / distributor / affiliate]
- Exclusive: [Yes/No]
- Territory: [scope]
- Commission: [detailed structure]
- Quota: [Yes/No] — Level: [detail]
- Governing law: Texas

FORMAT:
- Template form: fill-in fields = [___]
- Commission table: level | sales from-to | % commission
- Territory-map placeholder
- KPI dashboard: metric | target | actual | achievement %
- Ordering process: flowchart

TONE: Commercial, balanced, clear.
LENGTH: 8-12 pages + appendices.

CROSS-REFERENCE: This is the standard legal template for an agency agreement. For the commercial-partnership-focused version, see bb-sales/Partner Agreement Template.

NOTE: General information, not legal advice. Have a Texas attorney review before use.
```
