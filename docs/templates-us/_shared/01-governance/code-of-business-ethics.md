# PROMPT 11: Code of Business Ethics

#### Description
A code of conduct and business ethics for all staff. Covers: conflicts of interest (COI), anti-bribery/anti-corruption, confidentiality, whistleblowing, and social responsibility.

#### Information to collect (ask the user before generating)
1. Does the company have clear core values?
2. Any industry-specific ethics risks? (e.g. pharma, finance, construction)
3. Need an anonymous whistleblower channel/hotline?
4. Do you work with government / the public sector? (raises anti-bribery requirements)
5. Any foreign staff/partners? (FCPA, UK Bribery Act may apply)

#### Suggested template
Structure:
- **Message from the CEO** — 1 page, a personal commitment
- **Part 1** — Purpose, scope, commitment
- **Part 2** — Core values & conduct principles
- **Part 3** — Conflicts of interest: definition, examples, disclosure process
- **Part 4** — Anti-bribery & corruption: zero tolerance, gifts, entertainment (FCPA)
- **Part 5** — Information confidentiality & intellectual property
- **Part 6** — Workplace: anti-harassment, equal opportunity (EEOC), diversity
- **Part 7** — External relations: customers, partners, community, media
- **Part 8** — Whistleblowing: channel, process, whistleblower protection
- **Part 9** — Handling violations & sanctions
- **Appendix**: COI disclosure form, whistleblower form, FAQ

Confirm the structure before generating.

#### File-generation prompt
```
Create a Code of Business Ethics.

CONTEXT:
- Company: [Name] — Core values: [list]
- Industry: [industry] — Specific risks: [list]
- Whistleblower: [Yes/No] — Channel: [email / hotline / anonymous form]
- Public-sector partners: [Yes/No]
- International compliance: [FCPA / UK Bribery Act / None]

FORMAT:
- Open with a CEO message (1/2 page, personal voice, a commitment)
- Clear sections, each with: principle → concrete example → self-check questions
- A "5-question test" for each situation: Is it legal? → Is it policy-compliant? → How would it look in the news? → Is it fair to all parties? → Are you proud of this decision?
- Appendix: COI form + whistleblower form + a 10-question FAQ
- Design: friendly and readable — not overly legalistic

TONE: Formal but approachable, inspiring the right conduct.
LENGTH: 12-18 pages.
```
