### PROMPT 07: Search Engine Optimization (SEO) SOP

#### Description
A comprehensive SEO process — from website audit, keyword research, on-page optimization, and technical SEO, to SEO content, link building, and monitoring. Ensures the company's website is found on Google for target keywords.

#### Information to collect (ask the user before generating)
1. Current website? Estimated domain authority / traffic?
2. Done SEO before? Current results? Top keywords?
3. Main target keywords / topics?
4. A blog / content hub?
5. SEO team: how many? In-house or agency?
6. Tools in use? (Google Search Console, Analytics, Ahrefs, SEMrush?)

#### Suggested template
Structure:
- **Step 1** — SEO audit: technical audit, on-page audit, content audit, backlink audit
- **Step 2** — Keyword research: seed keywords, long-tail, search intent, difficulty/volume
- **Step 3** — On-page optimization: title, meta, headings, content, internal linking, schema
- **Step 4** — Technical SEO: site speed, mobile, crawlability, indexation, Core Web Vitals
- **Step 5** — Content creation: SEO content brief, writing guidelines, optimization checklist
- **Step 6** — Link building: guest posts, digital PR, broken-link, resource pages
- **Step 7** — Monitoring & reporting: rank tracking, traffic, conversions, monthly report

Confirm the structure before generating.

#### File-generation prompt
```
Create an SEO SOP.

CONTEXT:
- Company: [Name] — Website: [URL]
- Domain Authority: [DA] — Traffic: [monthly visitors]
- SEO history: [new / X months in]
- Target keywords: [5-10 main keywords]
- Blog: [Yes/No] — # posts: [number]
- Team: [number] — [in-house / agency]
- Tools: [GSC / GA / Ahrefs / SEMrush / other]

FORMAT:
- SEO audit checklist: 30+ items — Technical | On-Page | Content | Backlinks — ☐ Check × Status × Priority
- Keyword research template: table Keyword | Volume | Difficulty | Intent | Current Rank | Target | Content Needed
- On-page checklist: per page — Title ☐ | Meta ☐ | H1 ☐ | Content ☐ | Images ☐ | Internal Links ☐ | Schema ☐
- Content brief template: Target keyword | Search intent | Outline | Word count | Internal links | CTA
- Link-building tracker: table Target Site | DA | Status | Outreach Date | Response | Link URL
- Monthly SEO report: Rankings Δ | Traffic Δ | Top Pages | New Keywords | Actions
- 90-day SEO roadmap: table Week × Tasks — prioritized by impact

TONE: Technical SOP, systematic, measurable.
LENGTH: 6-8 pages.
```
