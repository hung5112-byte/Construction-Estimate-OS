# PROMPT 03: Brand Identity Guidelines

#### Description
A set of guidelines to keep the brand consistent across every touchpoint: logo, color, typography, imagery, tone of voice, do/don't. This file is the "bible" for marketing, design, and everyone who creates content.

#### Information to collect (ask the user before generating)
1. Do you already have a logo & identity? (source files / logo only / nothing yet)
2. Primary colors? (hex codes if available)
3. Fonts in use? (brand font / system font)
4. Brand personality? (e.g. professional-friendly, young-creative, luxury-refined)
5. Tone of voice: formal/casual, serious/playful, authoritative/friendly?
6. Main touchpoints: website, social media, brochure, business card, email, office?
7. Any clear DO/DON'T? (e.g. never use red, never abbreviate the company name)

#### Suggested template
Structure:
- **Introduction** — purpose of the guidelines, how to use them
- **Logo** — primary/secondary/icon, clear space, minimum size, placement rules, do/don't
- **Color** — primary palette (HEX/RGB/CMYK), secondary palette, usage ratio, accessibility contrast
- **Typography** — heading font, body font, sizes, hierarchy, web/print fallbacks
- **Imagery & Illustration** — style (photography/illustration), mood, do/don't, filter/treatment
- **Tone of Voice** — brand personality, voice attributes (3-5), writing guidelines, do/don't examples
- **Applications** — business card, email signature, social-media templates, presentation, letterhead
- **Digital** — website, app, social-media avatar/cover, ad templates
- **Do/Don't Gallery** — visual examples: right vs. wrong

Confirm the structure before generating.

#### File-generation prompt
```
Create Brand Identity Guidelines.

CONTEXT:
- Company: [Name] — Industry: [industry]
- Logo: [Yes/No] — File: [link if any]
- Colors: Primary [hex] | Secondary [hex] | Accent [hex]
- Fonts: Heading [font] | Body [font]
- Personality: [3-5 adjectives]
- Tone of voice: [describe]
- Main touchpoints: [list]
- Current do/don't: [list]

FORMAT:
- Structured manual, visual-heavy (describe examples even without images)
- Color swatches: HEX + RGB + CMYK + Pantone (if any)
- Typography specimens: size-hierarchy table
- Tone matrix: Context | We say... | We don't say...
- Application mockup descriptions: detail how to apply on each touchpoint
- Do/Don't: ✅ "Do this" vs. ❌ "Don't do this"
- Closing checklist: 10 self-check questions before publishing any material

TONE: Guidance — clear, visual, unambiguous.
LENGTH: 15-25 pages.
```
