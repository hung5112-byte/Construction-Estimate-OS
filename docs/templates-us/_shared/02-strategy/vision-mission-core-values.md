# PROMPT 02: Vision / Mission / Core Values (VMV)

#### Description
The VMV set is the north star for every decision in the business. Vision (where you're going), Mission (why you exist), Core Values (non-negotiable beliefs). This is the most-referenced file across the whole pack.

#### Information to collect (ask the user before generating)
1. Does the company already have a VMV? (create new / update / formalize)
2. Founder story: why did you start this business? The core motivation?
3. What will the company look like in 10-20 years?
4. 3-5 values the team REALLY lives by (not just wall art)?
5. Any "common enemy" or social problem the company wants to solve?
6. Who are the main stakeholders? (employees, customers, community, shareholders)

#### Suggested template
Structure:
- **Vision Statement** — one sentence, 10-20 words, ambitious, time-bound or timeless
- **Mission Statement** — 1-2 sentences answering: What? For whom? How? Why it matters?
- **Core Values** (3-5 values) — each with:
  - Value name (2-3 words)
  - Definition (1 sentence)
  - Expected behaviors (3-5 bullets: "We believe..." / "This means...")
  - Unacceptable behaviors (2-3 bullets)
  - A real example from the work
- **Brand Promise** — the commitment to customers (1 sentence)
- **Purpose Statement** — the reason to exist beyond profit (1 sentence, Simon Sinek "Start with Why" style)

Confirm the structure before generating.

#### File-generation prompt
```
Create a VMV — Vision / Mission / Core Values.

CONTEXT:
- Company: [Name] — Industry: [industry]
- Founder story: [summary]
- Current VMV (if any): Vision: [___] | Mission: [___] | Values: [___]
- 10-20 year ambition: [describe]
- Values the team actually lives by: [list]
- Social problem the company wants to solve: [describe]
- Main stakeholders: [list in priority order]

FORMAT:
- Vision: 1 sentence, ≤20 words, inspire & stretch
- Mission: 1-2 sentences, answering What/Who/How/Why
- Core Values: 3-5 values × (Name + Definition + DO behaviors + DON'T behaviors + Example)
- Brand Promise: 1 sentence, customer-facing
- Purpose: 1 sentence, Simon Sinek "Why"
- Test: run each statement through the filter — Specific? Memorable? Authentic? Differentiating? Actionable?
- Appendix: VMV communication plan — how to convey it to the team

TONE: Inspiring yet authentic, not hollow.
LENGTH: 3-5 pages.
```
