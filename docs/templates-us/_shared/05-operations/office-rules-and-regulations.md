### PROMPT 05: Office Rules & Regulations

#### Description
Rules for using the office — workplace conduct, shared facilities, meeting rooms, kitchen, parking, visitors, and fire safety. Unlike the Workplace Conduct & Work Rules (employment policy), this is the internal etiquette for office life.

#### Information to collect (ask the user before generating)
1. What kind of office? (co-working / private / factory + office)
2. Dedicated parking?
3. Do visitors come often? Reception process?
4. Any restricted-access areas?
5. Smoking, pets, food policy?

#### Suggested template
Structure:
- **General rules**: entry/exit hours, employee badge, dress code
- **Workspace**: tidiness, noise, personal calls
- **Meeting rooms**: booking, cleanup, time limits
- **Shared areas**: kitchen, restroom, hallway, elevator
- **Visitors & partners**: sign-in, reception, permitted areas
- **Parking & transport**: rules, locations
- **Safety**: fire safety, emergency exits, first aid
- **Violations**: reminder → warning → penalty

Confirm the structure before generating.

#### File-generation prompt
```
Create Office Rules & Regulations.

CONTEXT:
- Company: [Name] — Office type: [private / co-working / factory + office]
- Parking: [Yes/No]
- Frequent visitors: [Yes/No]
- Restricted area: [Yes/No]
- Special: [smoking / pets / dress code]

FORMAT:
- Poster-friendly: printable as a one-page wall poster
- Clear sections, with icon placeholders
- Do / Don't format: each rule has a "Do" and a "Don't"
- Office map: layout placeholder — exits, fire safety, first aid, restricted
- Emergency contacts: table Type | Contact | Phone

TONE: Friendly but clear, easy to remember.
LENGTH: 3-5 pages (+ a one-page poster).
```
