### PROMPT 20: Internal Communication SOP

#### Description
An internal-communication process — defining which channel carries which type of information, how to announce important news, and escalation for sensitive information.

#### Information to collect (ask the user before generating)
1. Current channels? (Email / Slack / Teams / Intranet / Meetings / Bulletin board)
2. Headcount? Multiple branches/sites?
3. Current communication problems? (rumors, missing info, too many channels, missed important announcements)
4. Who owns internal communication? (HR / Admin / Comms team)
5. All-hands frequency? An internal newsletter?
6. Any information needing a special process? (layoffs, restructure, crisis)

#### Suggested template
Structure:
- **Channel matrix**: information type × primary channel × secondary channel × frequency × sender
- **Important-announcement process**: Draft → Review → Approve → Send → Q&A → Follow-up
- **Sensitive-info escalation**: layoffs, restructure, crisis → a separate process
- **Feedback channels**: suggestion box, anonymous survey, 1-on-1, town hall
- **Content calendar**: week × type (weekly update, birthdays, wins, training...)
- **Measurement**: employee awareness survey, message read rate, engagement

Confirm the structure before generating.

#### File-generation prompt
```
Create an Internal Communication SOP.

CONTEXT:
- Company: [Name] — Current channels: [Email / Slack / Teams / Intranet / Meetings]
- Headcount: [number] — Multi-site: [Yes/No]
- Current problems: [describe]
- Owner: [HR / Admin / Comms]

FORMAT:
- Channel matrix: Information type | Primary channel | Secondary channel | Frequency | Sender
- Announcement protocol: flowchart — important news → Draft → Approve → Send → Q&A
- Escalation: sensitive news → special process + approved wording
- Feedback channels: suggestion box, anonymous survey, 1-on-1
- Content calendar: table Week × information type
- Measurement: employee awareness survey, message read rate

TONE: HR + Comms, inclusive, transparent.
LENGTH: 4-6 pages.
```
